# RxJS Operator & Subscription Flow

## Important Points

- `.pipe()` does NOT start execution
- Operators create NEW Observables
- Operators subscribe lazily
- Only `.subscribe()` starts execution

---

# Observable Chain

```ts
of(1, 2, 3)
  .pipe(
    map(x => x * 2),
    filter(x => x > 2)
  )
  .subscribe(console.log);
```

Conceptually:

```text
Source Observable
    ↓
Map Observable
    ↓
Filter Observable
    ↓
Subscriber
```

---

# What `.pipe()` Does

`.pipe()` only:
- connects operators
- builds Observable chain
- returns NEW Observable

It does NOT execute anything.

---

# Who Creates New Observable?

Each operator creates a new Observable.

Example:

```ts
map(x => x * 2)
```

Conceptually:

```ts
(source$) => new Observable(...)
```

Operators:
- subscribe to previous Observable
- transform values
- forward values

---

# How Execution Starts

Only:

```ts
.subscribe()
```

starts execution.

---

# Subscription Flow

Subscriptions happen backward:

```text
Subscriber
   ↓
Filter subscribes to Map
   ↓
Map subscribes to Source
```

---

# Value Flow

Values flow forward:

```text
Source → Map → Filter → Subscriber
```

Example:

```text
1 → 2 → filtered
2 → 4 → emitted
3 → 6 → emitted
```

Output:

```text
4
6
```

---

# Key Mental Model

## `.pipe()`

```text
Builds pipeline
```

## `.subscribe()`

```text
Turns pipeline ON
```

---

# Lazy Execution

Observables are lazy.

This does NOTHING:

```ts
const obs$ = of(1,2,3).pipe(map(x => x * 2));
```

Execution starts only after:

```ts
obs$.subscribe();
```
