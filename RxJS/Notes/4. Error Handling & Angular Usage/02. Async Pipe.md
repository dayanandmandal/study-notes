# Angular Async Pipe

## What is Async Pipe

The async pipe is an Angular built-in pipe used to subscribe to Observables or Promises directly in the template.

{{ observable$ | async }}

It automatically handles:

- subscription
- unsubscription
- change detection updates

---

## Why Async Pipe Exists

Without async pipe:

ngOnInit() {
this.sub = this.data$.subscribe(value => {
this.data = value;
});
}

ngOnDestroy() {
this.sub.unsubscribe();
}

Problems:

- manual subscription
- memory leaks risk
- boilerplate code
- manual change detection handling

---

## Automatic Subscription

<div *ngIf="user$ | async as user">
  {{ user.name }}
</div>

Behavior:

- Angular subscribes automatically
- receives emitted values
- updates template automatically

No subscribe() needed.

---

## Automatic Cleanup

Async pipe automatically unsubscribes when:

- component is destroyed
- view is removed (ngIf / routing changes)

Prevents:

- memory leaks
- zombie subscriptions

---

## Change Detection Integration

When new value arrives:

Observable emits → async pipe receives → UI updates

Works perfectly with:

- default change detection
- OnPush strategy

---

## Async Pipe with Observable

user$ = this.http.get('/api/user');

Template:

```html
<div>{{ user$ | async }}</div>
```

---

## Async Pipe with \*ngIf Pattern

```html
<div *ngIf="user$ | async as user">{{ user.name }}</div>
```

---

## Async Pipe with Loading Template

```html
<div *ngIf="data$ | async as data; else loading">{{ data }}</div>

<ng-template #loading> Loading... </ng-template>
```

---

## Async Pipe vs Subscribe

async pipe:

- auto subscription
- auto cleanup
- auto UI updates
- no memory leaks

subscribe:

- manual subscription
- manual cleanup
- higher risk of leaks
- more boilerplate

---

## Multiple Async Calls (Important)

Bad:
{{ user$ | async }}
{{ user$ | async }}

Good:

```html
<div *ngIf="user$ | async as user">{{ user.name }} {{ user.email }}</div>
```

Reason:

- avoids multiple subscriptions
- better performance

---

## Async Pipe with Promise

dataPromise = fetch('/api/data');

{{ dataPromise | async }}

Works with:

- Observable
- Promise

## Internal Working

ngOnChanges →
subscribe →
store value →
markForCheck →
update view →
unsubscribe on destroy

---

## When NOT to Use Async Pipe

- complex imperative logic needed
- side effects required
- multiple dependent stream orchestration in TS

---

## When to Use Async Pipe

- API data binding
- UI rendering
- NgRx store selectors
- state streams

---

## Common Pitfalls

- using async multiple times
- mixing subscribe + async
- not using \*ngIf aliasing
