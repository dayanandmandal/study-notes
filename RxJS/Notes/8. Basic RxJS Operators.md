# Basic RxJS Operators

## map()

Transforms each emitted value.

```ts
of(1, 2, 3).pipe(
  map(x => x * 2)
);
```

Output:

```text
2
4
6
```

Use when:

```text
Input Value → Transformed Value
```

---

## filter()

Emits only values matching a condition.

```ts
of(1, 2, 3, 4).pipe(
  filter(x => x % 2 === 0)
);
```

Output:

```text
2
4
```

Use when:

```text
Keep some values, discard others
```

---

## tap()

Perform side effects without modifying values.

```ts
of(1, 2, 3).pipe(
  tap(console.log)
);
```

Output:

```text
1
2
3
```

Common Angular use cases:

```ts
tap(() => this.loading = false)

tap(data => console.log(data))
```

Rule:

```text
Observe values, don't change them
```
Notes: *Although `tap()` can modify emitted objects because it receives the same object reference, it should not be used for data transformation. Mutating data inside `tap()` can introduce unexpected side effects and make streams harder to reason about. Use `map()` for transforming data and reserve `tap()` for side effects such as logging, analytics, or updating UI state.*

---

## take()

Take first N values and complete.

```ts
interval(1000).pipe(
  take(3)
);
```

Output:

```text
0
1
2
complete
```

Use when:

```text
Need only N emissions
```

---

## first()

Take the first matching value and complete.

```ts
of(1, 2, 3).pipe(
  first()
);
```

Output:

```text
1
```

Use when:

```text
Need only the first emission
```

---

## skip()

Ignore first N emissions.

```ts
of(1, 2, 3, 4).pipe(
  skip(2)
);
```

Output:

```text
3
4
```

Use when:

```text
Ignore initial values
```

---

## distinctUntilChanged()

Suppress consecutive duplicate values.

```ts
of(1, 1, 2, 2, 3, 3).pipe(
  distinctUntilChanged()
);
```

Output:

```text
1
2
3
```

Use when:

```text
Ignore repeated consecutive values
```

Common Angular use case:

```ts
formControl.valueChanges.pipe(
  distinctUntilChanged()
)
```

Prevents duplicate API calls for unchanged values.

---

# Quick Summary

```text
map()                  → Transform values

filter()               → Remove values

tap()                  → Side effects

take()                 → Take N values

first()                → Take first value

skip()                 → Ignore first N values

distinctUntilChanged() → Ignore consecutive duplicates
```
