# RxJS Core Concepts

## 1. Observable

### Definition
An **Observable** is a data producer. It emits values over time.

### Example

```js
import { Observable } from 'rxjs';

const observable = new Observable((subscriber) => {
  subscriber.next('Hello');
  subscriber.next('World');
  subscriber.complete();
});

observable.subscribe((value) => {
  console.log(value);
});
```

### Output

```txt
Hello
World
```

---

## 2. Observer

### Definition
An **Observer** is a consumer that receives values emitted by an Observable.

### Example

```js
const observer = {
  next: (value) => console.log('Value:', value),
  error: (err) => console.log('Error:', err),
  complete: () => console.log('Completed'),
};

observable.subscribe(observer);
```

### Output

```txt
Value: Hello
Value: World
Completed
```

---

## 3. Operators

### Definition
**Operators** transform, filter, or manipulate data emitted by an Observable.

### Example

```js
import { of } from 'rxjs';
import { map } from 'rxjs/operators';

of(1, 2, 3)
  .pipe(map((value) => value * 10))
  .subscribe(console.log);
```

### Output

```txt
10
20
30
```

---

## 4. Subscription

### Definition
A **Subscription** represents the execution of an Observable and allows you to unsubscribe.

### Example

```js
const subscription = observable.subscribe(console.log);

// Stop receiving values
subscription.unsubscribe();
```

### Why?

Prevents memory leaks and unnecessary processing.

---

## 5. Subject

### Definition
A **Subject** is both:
- An Observable
- An Observer

It allows multiple subscribers to receive the same emitted value.

### Example

```js
import { Subject } from 'rxjs';

const subject = new Subject();

subject.subscribe((value) => console.log('A:', value));
subject.subscribe((value) => console.log('B:', value));

subject.next(1);
subject.next(2);
```

### Output

```txt
A: 1
B: 1
A: 2
B: 2
```

### Why use Subject?

One producer → Multiple consumers

It is commonly used for:
- Event broadcasting
- Component communication
- Sharing data between subscribers

---

# Quick Summary

| Concept | Role |
|----------|------|
| Observable | Produces data |
| Observer | Consumes data |
| Operator | Transforms data |
| Subscription | Controls execution |
| Subject | Observable + Observer (multicast) |
