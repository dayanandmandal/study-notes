# RxJS Core Contracts

## Observable Contract

An Observable can emit:

```text
0..N next values
AND
either complete OR error
(optional)
```

Valid:

```text
next
next
next
complete
```

Valid:

```text
next
next
error
```

Valid:

```text
complete
```

Invalid:

```text
next
complete
next
```

Invalid:

```text
error
complete
```

Rules:

- After `complete()`, nothing else can be emitted.
- After `error()`, nothing else can be emitted.
- `complete()` and `error()` are mutually exclusive.

---

## Observer Contract

An Observer must implement one or more of:

```ts
{
  next?: (value) => void;
  error?: (err) => void;
  complete?: () => void;
}
```

Observer consumes values from an Observable.

Example:

```ts
obs$.subscribe({
  next: (value) => console.log(value),
  error: (err) => console.error(err),
  complete: () => console.log("done"),
});
```

---

## Subscription Contract

A Subscription represents an active execution.

```ts
const sub = obs$.subscribe(...);
```

Can be stopped via:

```ts
sub.unsubscribe();
```

Rules:

- Multiple `unsubscribe()` calls are safe.
- After unsubscribe, no more values are received.

---

## Subject Contract

A Subject is both:

```text
Observable
Observer
```

Can:

```ts
subject.subscribe(...)
subject.next(...)
subject.error(...)
subject.complete(...)
```

Rules:

- Can multicast to many subscribers.
- Follows Observable contract.
- After complete/error, no more values can be emitted.

---

## Operator Contract

A Pipeable Operator:

```text
Observable → Observable
```

Conceptually:

```ts
(source$) => transformed$;
```

Example:

```ts
map((x) => x * 2);
```

returns:

```ts
(source$) => newObservable;
```

Rules:

- Does not start execution.
- Returns a new Observable.
- Preserves lazy behavior.

---

## Pipe Contract

`.pipe()`:

```ts
obs$.pipe(op1(), op2(), op3());
```

is equivalent to:

```ts
op3()(op2()(op1()(obs$)));
```

Rules:

- Does not subscribe.
- Does not execute source.
- Only composes operators.

---

## Subject vs Observable

Observable:

```text
Produces values
Cannot call next()
Usually unicast
```

Subject:

```text
Produces values
Consumes values
Can call next()
Multicast
```

---

## share() Contract

`share()` converts:

```text
Cold Observable
        ↓
Shared Observable
```

Conceptually:

```text
Source
  ↓
Subject
 ↙   ↘
A     B
```

Rules:

- One source execution.
- Multiple subscribers share emissions.
- Internally uses a Subject.

---

## Interview Summary

```text
Observable = Producer

Observer = Consumer

Subject = Producer + Consumer

Subscription = Execution Handle

Operator = Observable → Observable

pipe() = Operator Composition

share() = Automatic Multicasting
```
