# Component Interaction

## Template Reference Variable

Creates a reference to an element or component inside a template.

```html
<input #searchBox />

<button (click)="searchBox.focus()">Focus</button>
```

### Mental Model

```txt
Local variable available only in template.
```

---

## Template Reference to Component

```html
<app-timer #timer></app-timer>

<button (click)="timer.start()">Start</button>
```

Allows template access to child component members.

---

## ViewChild

Used inside TypeScript to access:

- DOM elements
- Child components
- Directives

---

### Access DOM Element

Template:

```html
<input #searchBox />
```

Component:

```ts
@ViewChild('searchBox')
searchBox!: ElementRef;
```

Usage:

```ts
this.searchBox.nativeElement.focus();
```

---

### Access Child Component

```ts
@ViewChild(TimerComponent)
timer!: TimerComponent;
```

Usage:

```ts
this.timer.start();
```

---

## When is ViewChild Available?

```txt
After ngAfterViewInit
```

Bad:

```ts
ngOnInit() {
  this.searchBox.focus();
}
```

Good:

```ts
ngAfterViewInit() {
  this.searchBox.nativeElement.focus();
}
```

---

## ViewChild vs Template Variable

### Template Variable

```txt
Template only
```

Example:

```html
#searchBox
```

---

### ViewChild

```txt
TypeScript access
```

Example:

```ts
@ViewChild(...)
```

---

## Interview Questions

### When should ViewChild be used?

```txt
When parent needs direct access to child component or DOM element.
```

### When should ViewChild be avoided?

```txt
When communication can be achieved through @Input/@Output.
```

Excessive ViewChild creates tight coupling.
