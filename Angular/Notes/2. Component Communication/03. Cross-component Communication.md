# Cross Component Communication

Used when components are not directly related.

Example:

```txt
NavbarComponent

DashboardComponent

ProfileComponent
```

These components cannot communicate using @Input/@Output.

---

## Shared Service

Create a singleton service.

```ts
@Injectable({
  providedIn: "root",
})
export class UserService {}
```

Inject wherever needed.

```ts
constructor(
  private userService: UserService
) {}
```

### Mental Model

```txt
Service becomes a shared state container.
```

---

## Subject

A Subject is both:

```txt
Observable
+
Observer
```

Meaning it can:

```txt
Receive values
Emit values
```

---

### Create Subject

```ts
private refresh$ =
  new Subject<void>();
```

Emit:

```ts
this.refresh$.next();
```

Subscribe:

```ts
this.refresh$.subscribe(() => {
  this.loadData();
});
```

---

### Subject Characteristics

```txt
No initial value
Does not store last value
Only future subscribers receive events
```

Example:

```txt
Event Bus
Refresh Trigger
Notification Trigger
```

---

## BehaviorSubject

BehaviorSubject extends Subject.

```ts
private user$ =
  new BehaviorSubject<User | null>(null);
```

---

### Read Current Value

```ts
this.user$.value;
```

---

### Update Value

```ts
this.user$.next(user);
```

---

### Subscribe

```ts
this.user$.subscribe((user) => {
  console.log(user);
});
```

---

## BehaviorSubject Characteristics

```txt
Requires initial value
Stores latest value
New subscribers immediately receive latest value
```

---

## Subject vs BehaviorSubject

### Subject

```txt
No initial value
No stored value
Future events only
```

Example:

```txt
Refresh button clicked
```

---

### BehaviorSubject

```txt
Initial value required
Stores latest value
New subscribers get current value
```

Example:

```txt
Logged-in user
Theme
Language
Application state
```

---

## Common Interview Question

### Why use BehaviorSubject for state?

Because new subscribers immediately receive the latest state.

Example:

```txt
User logs in
↓
Header subscribes later
↓
Header immediately gets current user
```

With Subject:

```txt
Header receives nothing
until next emission
```
