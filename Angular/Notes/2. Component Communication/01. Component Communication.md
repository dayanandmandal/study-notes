# Component Communication

## Parent → Child (@Input)

Used when a parent component needs to pass data to a child component.

Parent:

```html
<app-user-card [user]="selectedUser"></app-user-card>
```

Child:

```ts
@Input() user!: User;
```

### Mental Model

```txt
Parent owns the data
Child receives the data
```

---

## Input Alias

```ts
@Input('userData') user!: User;
```

Parent:

```html
<app-user-card [userData]="selectedUser"></app-user-card>
```

Useful when public API name differs from internal property name.

---

## Required Input (Angular 16+)

```ts
@Input({ required: true })
user!: User;
```

Angular throws an error if parent forgets to provide the input.

---

## Child → Parent (@Output)

Used when a child needs to notify its parent.

Child:

```ts
@Output() save = new EventEmitter<User>();

saveUser() {
  this.save.emit(this.user);
}
```

Parent:

```html
<app-user-form (save)="onSave($event)"> </app-user-form>
```

### Mental Model

```txt
Parent sends data down
Child sends events up
```

---

## EventEmitter

Used with @Output.

```ts
@Output() delete =
  new EventEmitter<number>();
```

Emit value:

```ts
this.delete.emit(userId);
```

Parent receives:

```ts
onDelete(id: number) {}
```

---

## Interview Questions

### When to use @Input?

```txt
When parent provides data to child.
```

### When to use @Output?

```txt
When child notifies parent about actions/events.
```

### Can siblings communicate using @Input/@Output?

```txt
No.

Only parent-child communication.
```
