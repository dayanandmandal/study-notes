# Template Driven Forms

## What It Is

Template-driven forms keep most form logic in the template using `ngModel` and Angular directives.

Best for simple forms and quick scaffolding.

---

## Basic Setup

Import `FormsModule` in the feature or root module.

```ts
import { FormsModule } from '@angular/forms';

@NgModule({
  imports: [FormsModule]
})
export class AppModule {}
```

Template:

```html
<form #userForm="ngForm" (ngSubmit)="onSubmit(userForm)">
  <input name="name" [(ngModel)]="model.name" required />
  <input name="email" [(ngModel)]="model.email" email />
  <button [disabled]="userForm.invalid">Submit</button>
</form>
```

Component:

```ts
model = { name: '', email: '' };

onSubmit(form: NgForm) {
  console.log(form.value);
}
```

---

## Validation State Access

Use template references:

```html
<input name="email" [(ngModel)]="model.email" #email="ngModel" required email />

<div *ngIf="email.invalid && email.touched">Enter a valid email</div>
```

---

## When To Use

- small forms
- low business complexity
- teams comfortable with template-first approach

---

## Limitations

- harder to scale for large forms
- testing and dynamic controls are less ergonomic than reactive forms
- business rules become difficult to manage when spread across template

---

## Interview Quick Lines

- Template-driven forms are directive-based and template-centric.
- Great for simple forms, weaker for complex dynamic workflows.
- Validation and state are still available through `ngForm` and `ngModel`.
