# Custom Validators

## What It Is

Custom validators are user-defined validation functions for rules not covered by built-in validators.

They can be applied at control or form-group level.

---

## Control-Level Custom Validator

```ts
import { AbstractControl, ValidationErrors, ValidatorFn } from '@angular/forms';

export function noSpacesValidator(): ValidatorFn {
  return (control: AbstractControl): ValidationErrors | null => {
    const value = (control.value ?? '') as string;
    return value.includes(' ') ? { noSpaces: true } : null;
  };
}
```

Usage:

```ts
username: ['', [Validators.required, noSpacesValidator()]]
```

---

## Group-Level Custom Validator

Useful for cross-field rules like password confirm.

```ts
export const passwordMatchValidator: ValidatorFn = (group: AbstractControl) => {
  const password = group.get('password')?.value;
  const confirm = group.get('confirmPassword')?.value;
  return password === confirm ? null : { passwordMismatch: true };
};
```

Usage:

```ts
this.fb.group(
  {
    password: [''],
    confirmPassword: ['']
  },
  { validators: [passwordMatchValidator] }
);
```

---

## Error Display Pattern

```html
<div *ngIf="form.errors?.['passwordMismatch'] && form.touched">
  Password and confirm password must match.
</div>
```

---

## Best Practices

- return `null` when valid, error object when invalid
- keep validator pure and side-effect free
- use clear error keys (`passwordMismatch`, `noSpaces`)

---

## Interview Quick Lines

- Custom validators encode domain-specific rules.
- Group validators are essential for cross-field consistency.
- Good error keys make UI messaging and debugging cleaner.
