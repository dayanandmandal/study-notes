# FormArray

## What It Is

`FormArray` manages a dynamic list of controls or groups.

Use when item count is unknown at compile time.

Examples:

- multiple phone numbers
- list of addresses
- dynamic skill entries

---

## Basic Example

```ts
form = this.fb.group({
  skills: this.fb.array<FormControl<string>>([])
});

get skills(): FormArray<FormControl<string>> {
  return this.form.get('skills') as FormArray<FormControl<string>>;
}

addSkill() {
  this.skills.push(this.fb.control('', { nonNullable: true, validators: [Validators.required] }));
}

removeSkill(index: number) {
  this.skills.removeAt(index);
}
```

Template:

```html
<div formArrayName="skills">
  <div *ngFor="let control of skills.controls; let i = index">
    <input [formControlName]="i" />
    <button type="button" (click)="removeSkill(i)">Remove</button>
  </div>
</div>

<button type="button" (click)="addSkill()">Add Skill</button>
```

---

## FormArray of FormGroup

Use when each row has multiple fields.

```ts
addresses: this.fb.array([
  this.fb.group({ city: [''], zip: [''] })
])
```

---

## Common Mistakes

- mutating plain arrays instead of using FormArray API
- forgetting validation on dynamically added controls
- incorrect track strategy in large lists causing re-render overhead

---

## Interview Quick Lines

- `FormArray` is ideal for variable-length user input.
- Always manipulate controls via `push`, `insert`, `removeAt`, `clear`.
- Pair with typed forms for predictable value structure.
